# student-grade-analytics-system-c
a c project developed to practice **input validation** and **data analysis**.

## features

* **input validation:** ensures that all entered grades are within the valid range (0-100). prevents logical errors caused by invalid data.
* **statistical analysis:** calculates the class average and identifies the top-performing student.
* **pass/fail logic:** automatically categorizes scores based on a threshold (50) and reports the total count of passed and failed students.
